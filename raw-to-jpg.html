Which RAW Formats Are Actually Supported

RAW is not a single format. Every camera manufacturer uses its own container: Canon has CR2 and CR3, Nikon has NEF, Sony has ARW, Fujifilm has RAF, Panasonic has RW2, Olympus has ORF, Pentax has PEF, and so on. Underneath, some are TIFF-based (DNG, NEF, CR2 in their older forms) and some are entirely proprietary.

This tool uses UTIF.js, which decodes TIFF-based containers. In practice, that means:

Format Support Notes
DNG (Adobe Digital Negative) Reliable TIFF-based, well-supported by UTIF.js. Recommended input format.
NEF (Nikon) Sometimes TIFF-based container, but the embedded image may be decoded instead of the raw mosaic.
CR2 (Canon, older) Sometimes TIFF-based; the tool may extract the embedded JPEG preview, not the raw data.
ARW (Sony) Unreliable Proprietary; the embedded preview may or may not decode.
CR3 (Canon, newer) No Newer ISO base media container, not TIFF. Not supported.
RAF (Fujifilm) No Proprietary container with two raw channels. Not supported.
ORF, RW2, PEF, IIQ, others Variable Depends on whether the container is TIFF-based and how the pixels are stored.

If your file cannot be decoded, the most reliable fix is to convert it to DNG in your camera manufacturer's software (Canon DPP, Nikon NX Studio, Sony Imaging Edge, Adobe DNG Converter, etc.) and then upload the DNG here. DNG is Adobe's open format and is designed for exactly this kind of interchange.

Colour Processing — What Happens to Your Raw Data

A camera RAW file does not contain an RGB image. It contains a single-channel mosaic of pixel values, where each pixel records only one of R, G, or B — a layout called a Bayer filter array. Turning that mosaic into a viewable image requires:

  • Demosaicing — reconstructing three colour channels per pixel by interpolating the values around it.
  • White balance — applying the camera's colour temperature and tint multipliers to correct the grey point.
  • Colour matrix — mapping the sensor's colour response to the sRGB working space using a matrix stored in the RAW metadata.
  • Tone curve — mapping the linear sensor values to a display-referred range, since sensors are linear but human vision is not.
  • Gamma correction — applying the sRGB transfer curve for display.

This tool does none of those steps. UTIF.js, the library used here, performs a rough decode of the TIFF structure and produces pixel data without a full raw pipeline. That means:

  • Colours may look flat, green-tinted, or otherwise wrong compared to your camera's JPG.
  • Brightness and contrast may be off, because the sensor data is linear and no tone curve is applied.
  • The result will not match what you see in Lightroom, Capture One, or your camera's preview.

If you need accurate colour from a RAW file, use a real raw processor: Lightroom, Capture One, RawTherapee, Darktable, or the manufacturer's own software. This tool is a best-effort browser-based conversion, not a substitute for a proper raw editor.

Orientation

Cameras record the orientation of the shot (portrait, landscape, upside-down) in the RAW metadata, and image viewers rotate the photo to match when they display it. This tool does not apply that rotation. If your camera was held sideways when the photo was taken, the JPG may appear rotated 90° from how you expect it.

To fix it: rotate the JPG afterwards in any image viewer or editor, or set the image orientation in your camera before shooting. There is no orientation option in this tool because the tool does not read the orientation tag reliably across all RAW formats.

EXIF — Preserved or Lost?

All EXIF metadata is lost in the conversion. The output JPG contains only pixel data. The following are not carried over:

  • Camera make and model
  • Lens information
  • Exposure settings (shutter speed, aperture, ISO)
  • GPS coordinates
  • Capture timestamp
  • White balance as recorded by the camera
  • Colour space tag
  • Orientation tag

The reason is technical: the decoded pixels are drawn onto a canvas, and the browser's JPEG encoder does not write EXIF data. To retain EXIF you need a tool that reads the RAW's metadata block and re-embeds it in the JPEG, which is outside what a browser can reliably do.

This has a privacy upside. Sharing a converted JPG will not leak your camera model or GPS location. If you specifically want to publish a photo without metadata, this is a convenient side effect.

JPEG Quality Control

JPEG is a lossy format. Every save discards some information to reduce file size. The quality setting controls how much is discarded:

Setting Quality Value Typical Use
High (Smaller) 0.70 Email attachments, quick previews, mobile uploads
Very High 0.85 General use, sharing, printing — the default
Maximum (Larger) 0.95 Printing at large sizes, archival JPG copies

Because the RAW data is lossy-compressed on export as JPEG, and because the browser's decode pipeline is already approximate, use Maximum (0.95) when the file will be edited further or printed. Use Very High (0.85) for general sharing.

Real Limitations You Should Know

  • Not all RAW formats decode. Only TIFF-based containers are handled. CR3, RAF, and most proprietary formats will fail.
  • No raw demosaicing. The output is not a proper raw development; it is whatever UTIF.js can extract.
  • Colours will differ from your camera's JPG. No white balance, no colour matrix, no tone curve.
  • EXIF is stripped. Camera settings, GPS, and capture date are not carried over.
  • Orientation is not applied. Portrait shots may appear rotated.
  • Selectable text is not relevant here — RAW files contain no text, but note that the output is a plain image, not a document.
  • Quality is not recoverable. Once converted to JPG, the raw data cannot be recovered from the output. Keep the original RAW file if you may want to re-edit later.

RAW to JPG Questions

Which RAW formats actually work?

DNG (Adobe's open format) works reliably. Some TIFF-based formats like NEF and CR2 may work if the embedded preview can be decoded. CR3, RAF, and most modern proprietary formats do not work because they are not TIFF-based and require a full raw pipeline. If a file fails, convert it to DNG first.

Will my colours match the camera's JPG?

No. This tool does not perform demosaicing, white balance, colour matrix mapping, or tone curve application. The output colours will look different from what your camera produces. Use a real raw processor if colour accuracy matters.

Is EXIF data preserved?

No. Camera model, lens, exposure settings, ISO, GPS coordinates, and capture date are all stripped during conversion. The output JPG contains pixel data only. This is good for privacy but means the descriptive metadata is lost.

Is orientation applied?

No. The orientation tag is not read, so portrait photos may appear rotated 90° from how you expect. Rotate the JPG afterwards in any image viewer if needed.

What quality setting should I use?

Very High (0.85) is the default and works for sharing and general use. Use Maximum (0.95) if the JPG will be edited further or printed at large sizes. Use High (0.70) if file size matters more than detail.

Can I recover the raw data from the JPG?

No. Once the RAW is converted to JPG, the original sensor data is gone. The JPG contains a compressed 8-bit image, not the 12-bit or 14-bit sensor mosaic. Keep the original RAW file if you may want to re-edit later.

Why is the output JPG sometimes smaller than expected?

If UTIF.js extracted an embedded preview image rather than the full raw data, the output dimensions may match the preview resolution (often 1600×1200 or similar) rather than the camera's full sensor resolution. This is a limitation of the decoder.

Is my data safe?

Yes. All decoding and encoding happens locally in your browser using UTIF.js. Your RAW files are never uploaded to any server. You can disconnect from the internet after the page loads and the tool will continue to work.

How do I convert a CR3, RAF, or other unsupported RAW?

Convert it to DNG first using Adobe DNG Converter (free), or to JPG using your camera manufacturer's software (Canon DPP, Nikon NX Studio, Sony Imaging Edge, Fujifilm X Raw Studio, etc.). Then upload the DNG or JPG here if you still need to re-process it.

Does this tool support batch conversion?

Yes. Drag and drop several RAW files or select them all in the file picker. Each file is converted independently with the same settings. You can then download everything as a ZIP archive or download them individually.

What is the maximum file size?

About 100 MB per RAW file. RAW files are large — a full-frame 45 MP RAW can be 50–80 MB — so this limit is generous. Very large files may take a moment to decode.

Why does my raw file fail to convert?

The most common reason is that the file is not a TIFF-based container, so UTIF.js cannot parse it. CR3, RAF, and many newer RAW formats fall into this category. The fix is to convert the file to DNG or JPG using another tool, then upload the converted file here.
