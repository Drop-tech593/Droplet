Frequently Asked Questions

Is my data safe?

Yes! All conversions happen locally in your browser. Your JSON data is never uploaded to any server and is automatically deleted when you close the page.

What JSON structures are supported?

This converter supports arrays of objects (most common), single objects, and nested objects. For nested objects, keys are flattened using dot notation (e.g., "user.name").

What about nested JSON?

Nested JSON objects are automatically flattened. For example, `{"user": {"name": "John", "age": 30}}` becomes columns `user.name` and `user.age`.

Can I convert JSON from APIs?

Yes! Simply paste the API response JSON into the textarea and click convert. The tool will handle arrays, objects, and nested structures.

Are there file size limits?

Since everything runs locally, limits depend on your device's memory. Most modern browsers handle JSON files up to 10MB without issues.
