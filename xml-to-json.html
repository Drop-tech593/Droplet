Frequently Asked Questions

Is my data safe?

Yes! All conversions happen locally in your browser. Your XML data is never uploaded to any server and is automatically deleted when you close the page.

What XML features are supported?

This converter supports nested XML elements, attributes (preserved as `_attributes`), text content, CDATA sections, and namespaces. Empty elements become empty objects.

How are attributes handled?

XML attributes are preserved in the JSON output as an `_attributes` object. For example, `` becomes `{"person": {"_attributes": {"id": "123"}}}`.

Are there file size limits?

Since everything runs locally, limits depend on your device's memory. Most modern browsers handle XML files up to 10MB without issues.

What about CDATA sections?

CDATA sections are preserved as text content in the JSON output. They are treated as regular text nodes.
