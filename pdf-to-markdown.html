What Gets Converted

The converter reads each page of the PDF, extracts the text layer, and rebuilds the content as Markdown. Different kinds of content are handled differently:

  • Headings — detected by font size. A line whose font is noticeably larger than the body text becomes #, ##, or ### depending on how much larger it is. The "Auto-detect" mode uses a moderate threshold; "Aggressive" also treats short, title-like lines as headings.
  • Paragraphs — lines that belong to the same block of text are joined into one paragraph. A new paragraph starts when there is a large vertical gap or when the previous line ends with a period, question mark, or exclamation mark.
  • Lists — bullet characters (•, ·, ▪, and similar) and numbered items (1., 2)) are recognised and converted to Markdown list syntax. You can turn list detection off if you want every line to remain a plain paragraph.
  • Links — any text that looks like a URL becomes a Markdown link. Because PDFs do not store anchor text separately, the URL itself is used as the link text.
  • Code — inline code is detected when the extracted text uses a monospace font. There is no language detection; code blocks come through as plain text unless the surrounding formatting suggests otherwise.
  • Tables — simple, evenly spaced tables may be detected and converted to Markdown table syntax. Complex tables (merged cells, nested tables, tables with images) often come through as separate lines of text instead.
  • Horizontal rules — a line of three or more dashes or underscores is converted to ---.
  • Page breaks — each PDF page is separated by a horizontal rule (---) so you can see where pages begin and end.

Scanned PDFs — What Happens

A scanned PDF is a set of images, not text. There is no text layer for the converter to read, so the output will be empty or near-empty. This is not a bug — it is a fundamental limitation of extractive conversion.

To turn a scanned PDF into Markdown you need OCR (Optical Character Recognition), which reads the pixels and guesses the characters. That is a separate process and is not performed by this tool. If you have a scanned PDF, run it through an OCR tool first, then convert the resulting text-based PDF here.

A quick way to check: open the PDF in your browser and try to select text with your mouse. If you can select it, the PDF has a text layer and will convert. If you cannot, it is a scanned image and needs OCR.

What Does Not Survive Conversion

  • Images — this tool extracts text only. Images embedded in the PDF are not included in the Markdown. If you need images, extract them separately.
  • Exact positioning — PDFs place every character at a precise coordinate. Markdown is a reflowable format. Text that was laid out in columns or wrapped around images will reflow into a single stream.
  • Fonts and colours — Markdown has no concept of font family or text colour. Bold and italic are detected from font weight and style, but the specific font and colour are lost.
  • Tables with merged cells — Markdown tables do not support merged cells. These come through as plain text.
  • Headers and footers — repeating page headers and footers are included in the output because the converter reads every line. You may need to remove them manually after conversion.
  • Footnotes — footnote text usually appears at the bottom of the page in the output rather than as linked references.

Options — Heading and List Detection

Two settings control the output:

  • Heading detection — "Auto-detect" is the default and works well on most documents. "Plain text" disables heading detection entirely, producing paragraphs only. "Aggressive" also treats short, title-like lines as level-3 headings, which is useful for documents that use bold text instead of larger font sizes for headings.
  • List detection — "Auto-detect" recognises bullets and numbered items. "Plain text" leaves every line as a paragraph. Turn list detection off if your PDF uses dashes or numbers as part of normal prose rather than as list markers.

Privacy — Client-Side Conversion

PDF parsing uses the open-source PDF.js library, which runs entirely in your browser. Your PDF is read into memory and never transmitted. The only external resources loaded are the libraries themselves from a CDN.

Practical Examples

Converting documentation for a wiki: Load the PDF, run the conversion, and paste the Markdown into your wiki editor. Headings and lists carry over; images need to be added separately.

Extracting a README from a PDF spec: Use Aggressive heading detection if the spec uses bold text rather than large fonts for its section titles. Turn list detection off if the spec uses numbered paragraphs that are not really lists.

Preparing notes for a note-taking app: Convert the PDF to Markdown and import the .md file into Obsidian, Notion, or Logseq. The heading structure becomes the outline.

Version-controlling a document: Markdown is plain text, so it works with Git. Convert once, then track changes as diffs.

PDF to Markdown Questions

Will the Markdown look exactly like the PDF?

No. Markdown is a reflowable format. Headings, paragraphs, and lists keep their structure, but exact line breaks, column layouts, and font choices are lost. For a pixel-perfect copy, use the original PDF.

Are images preserved in the Markdown?

No. This tool extracts text only. Images embedded in the PDF are not included in the output. You would need to extract them separately and add them to the Markdown manually.

Why is my scanned PDF producing empty output?

A scanned PDF contains images, not text. There is no text layer for the converter to read. You need OCR (Optical Character Recognition) to turn the scanned images into text first. This tool does not perform OCR.

Are tables converted to Markdown tables?

Simple, evenly spaced tables may be detected and converted to Markdown table syntax. Complex tables — with merged cells, nested tables, or images inside cells — usually come through as separate lines of text. Markdown tables do not support merged cells, so those cannot be represented accurately.

How are headings detected?

Headings are detected by font size. A line whose font is noticeably larger than the body text becomes a heading. "Auto-detect" uses a moderate threshold; "Aggressive" also treats short, title-like lines as level-3 headings. If your PDF uses bold text instead of larger fonts for headings, try the Aggressive mode.

How are links handled?

Any text that looks like a URL becomes a Markdown link. Because PDFs do not store anchor text separately, the URL itself is used as the link text. If the PDF had a hyperlink with custom text, the extracted text will show the visible label but the URL may not be preserved as a link.

Does the converter preserve code blocks?

Inline code is detected when the PDF uses a monospace font. Code blocks are not specifically detected — they come through as plain text unless the surrounding formatting suggests a block. There is no language detection.

What happens to headers and footers?

Repeating page headers and footers are included in the output because the converter reads every line on every page. After conversion you may want to remove them manually. There is no automatic detection of running headers and footers.

Can I convert a password-protected PDF?

No. The converter can only read PDFs that open without a password. If your PDF requires a password, remove the protection first using a dedicated PDF tool, then convert it here.

Is my PDF uploaded to a server?

No. All parsing and conversion happen locally in your browser using PDF.js. Your file never leaves your device. You can disconnect from the internet after the page loads and the tool will continue to work.

What is the difference between this tool and the PDF to TXT converter?

This tool produces Markdown with heading markers, list syntax, and paragraph structure. The PDF to TXT converter produces plain text with no formatting. If you want the structure preserved, use this tool. If you only need the raw words, TXT is simpler.

Can I edit the Markdown after downloading?

Yes. The output is a plain .md file. You can open it in any text editor, paste it into a note-taking app, or commit it to a Git repository. Markdown is designed to be edited by hand.
