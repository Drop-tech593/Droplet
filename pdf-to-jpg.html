How Page-to-Image Conversion Works

The converter reads your PDF with PDF.js, renders each page onto a canvas at the resolution you choose, and exports the canvas as a JPEG image. A 12-page PDF produces 12 JPG files, one per page, in the same order as the original document.

This is a rasterisation process. The PDF's original content — text, vector graphics, images — is drawn onto a pixel grid at a specific scale. Once rendered, the output is a flat image. Text in the JPG is no longer selectable, and vector lines become pixels.

The advantage of rasterisation is fidelity: the JPG looks exactly like the PDF page, with every font, image, and layout element preserved. The disadvantage is that the output is a picture, not a document. It cannot be searched, edited, or scaled indefinitely without loss of quality.

JPG Quality — What the Slider Does

JPEG is a lossy compression format. When you save an image as JPG, the encoder discards some visual information to reduce file size. The quality setting controls how much is discarded.

Setting Quality Value Typical Use Typical File Size
High (Smaller) 0.70 Email attachments, quick previews, web thumbnails ~100–200 KB per page
Very High 0.85 General use, sharing on messaging apps, archiving ~250–500 KB per page
Maximum (Larger) 0.95 Printing, detailed graphics, further editing ~500 KB–1.5 MB per page

At 0.95 the difference from the original is usually invisible to the eye. At 0.70 you may notice slight blurring around sharp text edges and faint banding in gradient areas. For documents that will be printed or zoomed in, use the Maximum setting.

Resolution — What "Image Size" Controls

Resolution determines how many pixels wide and tall the output image is. Higher resolution means more detail, but also a larger file. The "Image Size" setting caps the longest edge of the rendered page.

Setting Longest Edge Best For
Original Size Page's native resolution Maximum detail — no downscaling applied
4K (3840px) 3840 pixels Large displays, printing, high-DPI screens
HD (1920px) 1920 pixels Standard laptop and desktop displays
HD Ready (1280px) 1280 pixels Web embedding, presentations
Web (800px) 800 pixels Thumbnails, previews, mobile screens

A standard A4 page (210 × 297 mm) rendered at 1920 px on the long edge produces an image roughly 1358 × 1920 pixels. At 3840 px it is roughly 2717 × 3840 pixels. Original Size renders at the page's natural scale with no downscaling, which can produce very large files for high-resolution PDFs.

Colour Mode

Two colour modes are available. Color preserves the original colours of the page. Grayscale converts everything to shades of grey, which reduces file size by roughly 20–40% and is often preferred for text-heavy documents where colour adds no information.

Grayscale is applied at render time, so the output JPG is a true greyscale image rather than a colour image with desaturated pixels. This is more efficient and produces cleaner output.

Multiple Pages — Naming and Order

Each page produces one JPG with a predictable filename. If your PDF is called report.pdf, the outputs are:

  • report_page_001.jpg
  • report_page_002.jpg
  • report_page_003.jpg
  • … and so on.

The three-digit zero-padding means the files sort correctly in any file manager, even for documents with more than 100 pages. The page number in the filename always matches the page number in the original PDF.

Output order is always the same as the PDF's page order. If you need a different order, rename the files after downloading.

Downloading — Individual Files vs. ZIP

Two download options are offered:

  • Download Individual — each JPG downloads as a separate file. Your browser may ask permission to download multiple files. There is a 300 ms delay between each download to prevent the browser from blocking them.
  • Download All (ZIP) — all JPGs are packaged into a single ZIP archive named after the original PDF, for example report_images.zip. This is usually the faster and cleaner option for multi-page documents.

The ZIP is generated in your browser using JSZip. Nothing is uploaded. For a single-page PDF, the ZIP option downloads the JPG directly rather than wrapping it in an archive.

A Worked Example

Take a 3-page PDF called invoice_packet.pdf at 8.5 × 11 inches (Letter size). With settings Very High quality, HD (1920px), and Color, the conversion produces:

  • invoice_packet_page_001.jpg — 1483 × 1920 px, ~340 KB
  • invoice_packet_page_002.jpg — 1483 × 1920 px, ~410 KB
  • invoice_packet_page_003.jpg — 1483 × 1920 px, ~295 KB

The total output is about 1 MB, which fits comfortably in an email attachment. If you needed to print these pages at 300 DPI, you would choose 4K and Maximum instead, which would produce files roughly 4× larger.

Scanned PDFs — Perfect Match

Scanned PDFs work exceptionally well with this tool. A scanned PDF is already a set of page images — the converter simply renders them at the chosen resolution and exports them as JPG. There is no loss of fidelity because the source is already raster.

This makes the tool useful for extracting individual pages from a scanned book, sending a signed contract page as an image, or converting a scanned receipt into a format that can be attached to an expense report.

What Is Not Preserved

  • Selectable text. The output is an image. You cannot select or search text within the JPG. If you need searchable text, use the PDF to TXT converter instead.
  • Hyperlinks. Clickable links in the PDF are rendered as visible text but are not clickable in the JPG.
  • Form fields. Interactive form fields become flat pixels. They cannot be filled in the output.
  • Metadata. The output JPG does not inherit the PDF's metadata, and no EXIF data is written. GPS location, camera model, and other tags are absent.

Privacy — Client-Side Rendering

PDF parsing uses the open-source PDF.js library and ZIP generation uses JSZip. Both run entirely in your browser. Your PDF is read into memory and never transmitted. The only external resources loaded are the libraries themselves from a CDN. You can disconnect from the internet after the page loads and the tool will continue to work.

PDF to JPG Questions

Is my data safe?

Yes. All conversion happens locally in your browser using PDF.js. Your PDF is never uploaded to any server. You can disconnect from the internet after the page loads and the tool will continue to work.

How does the conversion work?

Each PDF page is rendered onto an HTML canvas at the resolution you choose, then exported as a JPEG image. A 10-page PDF produces 10 JPG files, one per page, in page order.

What JPG quality should I choose?

Very High (0.85) is the default and works well for most uses — sharing, archiving, and general viewing. Choose Maximum (0.95) if you plan to print or edit the images further. Choose High (0.70) if file size matters more than detail, for example when emailing.

What does "Image Size" control?

It caps the longest edge of the rendered page in pixels. HD (1920px) is a good default for screen viewing. 4K (3840px) is for printing or large displays. Web (800px) produces small files suitable for thumbnails. Original Size renders at the page's natural scale with no downscaling.

Can I convert a scanned PDF to JPG?

Yes, and it works very well because a scanned PDF is already a set of page images. The output JPG looks exactly like the scanned page — no additional quality loss beyond the JPEG compression you choose.

Will I lose image quality?

JPEG is a lossy format, so some quality is lost at every quality setting except the theoretical maximum. At Very High and Maximum, the loss is imperceptible for most documents. At High (0.70), you may notice slight blurring around sharp text edges.

Can I download all pages as a ZIP?

Yes. Click "Download All (ZIP)" in the results section. All pages are packaged into a single ZIP file named after the original PDF. The ZIP is created in your browser using JSZip — nothing is uploaded.

Can I download individual pages?

Yes. Click "Download Individual" or use the individual download links in the results section. There is a short delay between each download to prevent the browser from blocking them as a suspicious multiple-download action.

What is the maximum file size?

About 100 MB. The practical limit depends on your device's memory and the number of pages. Very large PDFs with hundreds of pages may take a while and use significant memory.

Can I convert a password-protected PDF?

No. The tool can only read PDFs that open without a password. If your PDF requires a password, remove the protection first using a dedicated PDF tool, then convert it here.

What colour mode should I use?

Color preserves the original appearance. Grayscale reduces file size by 20–40% and is often better for text-heavy documents. For photos, charts, or anything where colour carries information, use Color.

Can I convert just one page?

Not directly with this tool — it converts every page. If you only need one page, use the Split PDF tool first to isolate that page, then convert the one-page PDF here.
