Frequently Asked Questions

Is my data safe?

Absolutely! All conversions happen entirely in your browser. Your files never leave your device, are never uploaded to any server, and are never stored anywhere.

Are there file size limits?

Since everything runs locally, file size limits depend on your device's memory. Most modern browsers can handle files up to 2GB without issues.

What file formats are supported?

We support HEIC to JPG, JSON to CSV, EPUB to PDF, SVG to PNG, PDF to DOCX, WebP to PNG, PSD to PNG, and GIF to PNG. More formats are coming soon!

Do I need an account?

No account needed. Droplet is completely free to use with no registration required.

How do I use Droplet?

Simply select a file using the "Select File" button or drag and drop it into the dropzone. Your file will be converted instantly in your browser.
