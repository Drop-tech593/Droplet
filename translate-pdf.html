Translating PDFs: the complete guide

A PDF is a rendering of a document, not a source file. Its text is stored as drawing instructions — glyph by glyph, positioned on the page. There is no "translate this PDF" button in the format itself, because translation requires understanding language, and a PDF stores no linguistic structure. To translate a PDF, you first have to extract its text, then translate that text, then reconstruct a document from the translation.

This tool does exactly that. It reads the PDF, extracts the text from each page, groups it into paragraphs, sends each paragraph to a translation engine, and then reassembles the translated paragraphs into a new PDF, DOCX, or XLSX document.

What you get is a clean, readable, correctly-ordered translation. Every paragraph from the original appears in the output, in the same order.

Frequently Asked Questions

Is my PDF uploaded to a server?

The PDF file itself is never uploaded. It is opened and parsed inside your browser. Only the plain text extracted from the PDF is sent to the translation engine.

Is this tool free?

Yes, completely free. The default translation engine (MyMemory) has a daily quota per IP address.

What languages are supported?

Fourteen target languages: Afrikaans, Arabic, Chinese (Simplified), Dutch, French, German, Italian, Japanese, Korean, Portuguese, Russian, Spanish, Swahili, and Zulu.

Does it preserve the original layout?

No. The translated output is a clean, reflowed document with the same paragraph order. Layout preservation is not achievable in a browser without breaking text.

Is the translated PDF text selectable?

Yes. The exported PDF contains real text, not images, so it can be searched, copied, and re-edited.
