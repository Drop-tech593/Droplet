What This Tool Does

The converter takes one or more JPG images, embeds each one into its own PDF page, and produces a set of PDF files — or a single PDF per image, depending on your workflow. You control the page size, image quality, and colour mode before converting.

Everything runs in your browser. The images are read into memory, rendered onto a PDF page using html2pdf and jsPDF, and written out as a downloadable file. Nothing is uploaded.

Multiple Images and Page Ordering

You can select as many JPG files as you like in a single batch. The converter processes them in the order they appear in the file picker or the drag-and-drop list. Each image becomes one PDF file, named after the source image. For example:

  • photo1.jpg → photo1.pdf
  • photo2.jpg → photo2.pdf
  • scan001.jpg → scan001.pdf

Each output is a single-page PDF containing one image. If you want multiple images in a single multi-page PDF, the workflow is: convert each JPG to a single-page PDF here, then combine them using the Merge PDF tool.

The converter does not reorder images. If you need a specific order, rename the files before uploading (for example 01-cover.jpg, 02-intro.jpg, and so on) or use the Merge PDF tool after conversion to drag them into the desired sequence.

Page Sizing — A4, Letter, Legal, and Fit to Image

Four page-size options control how the image sits on the PDF page:

Option Dimensions Behaviour
A4 210 × 297 mm Image is centred on an A4 page, scaled to fit inside a small margin
Letter 8.5 × 11 in (215.9 × 279.4 mm) Same as A4 but with US Letter dimensions
Legal 8.5 × 14 in (215.9 × 355.6 mm) Same as A4 but with US Legal dimensions
Fit to Image Matches the image's own dimensions PDF page is exactly the size of the image

For most use cases — printing, emailing, archiving — A4 or Letter is the right choice. Use Fit to Image when you want the PDF page to match the image exactly, with no surrounding paper-like background. Fit to Image is common for digital-only PDFs and for images that already include their own border or background.

Aspect Ratio and Margins

The converter preserves the image's aspect ratio. A landscape photo stays landscape, a portrait scan stays portrait. It is never stretched or squashed.

On A4, Letter, and Legal pages, a small margin is left around the image so it does not run right to the paper edge. The image is scaled to fit inside the printable area while preserving its aspect ratio. If the image's aspect ratio does not match the page's aspect ratio, white space appears on two sides — top and bottom for a landscape image on a portrait page, or left and right for a portrait image on a landscape page.

For borderless results, choose Fit to Image. The PDF page is exactly the size of the image, so there is no extra margin and no letterboxing.

Orientation

Page orientation is determined automatically from the image. A landscape image produces a landscape page, a portrait image produces a portrait page. There is no manual orientation toggle because the image's own shape is the authoritative source.

In the current version, all pages in a batch use portrait orientation by default. If you need landscape for a specific image, use the Fit to Image option, which inherits the image's orientation exactly.

Image Quality and Compression

The "Image Quality" setting controls how much compression is applied when the image is embedded into the PDF.

Setting Rendering Scale Typical Use
Low (Faster) 1× Quick previews, small PDFs for email, thumbnails
Medium 1.5× General use, sharing, archiving — the default
High (Better Quality) 2.5× Printing, detailed photos, archival copies

The rendering scale controls how many pixels are drawn per inch of PDF page. At higher scales, the PDF file gets larger but the image looks sharper when zoomed or printed.

JPEG compression is applied at 0.92 quality, which is visually near-lossless for most photographs. The trade-off between file size and quality is controlled primarily by the rendering scale, not the compression level.

Colour Mode

Two colour modes are available. Colour preserves the original colours of the image. Grayscale converts the image to shades of grey before embedding it, which reduces file size by roughly 30–50% and is often preferred for text-heavy scans and documents where colour adds no information.

Practical Examples

Converting a photo for email: Use A4, Low quality, Colour. The result is a small PDF that attaches easily to an email and opens on any device.

Archiving a signed contract scan: Use A4, High quality, Colour. The PDF preserves the signature and any hand-written notes at high resolution.

Batch converting a folder of receipts: Select all the JPGs, choose A4, Medium quality, Grayscale. The result is a set of small PDFs that are easy to file.

Creating a borderless image PDF: Choose Fit to Image, High quality, Colour. The PDF page is exactly the size of the image, with no surrounding margin.

Preparing slides for a presentation backup: Convert each slide image to Fit to Image at High quality, then merge the PDFs into a single deck using the Merge PDF tool.

What Is Not Preserved

  • Image metadata. EXIF data (GPS location, camera model, capture date) is stripped during conversion. The output PDF does not carry it.
  • Original filename beyond the base name. The output PDF is named after the image's base name with a .pdf extension. The original extension and any extra metadata in the filename are not preserved.
  • Multi-page PDFs from multiple images in one file. Each image produces its own single-page PDF. To combine them, use the Merge PDF tool.
  • Image transparency. JPG does not support transparency, so this does not apply. For transparent images (PNG with alpha), the transparent areas are filled with white in the output PDF.
  • Vector graphics. JPG is a raster format. The image is embedded as a raster image in the PDF, not as vector paths.

Privacy — Client-Side Conversion

The images are read into the browser's memory using the File API and rendered onto a canvas. The PDF is assembled using the open-source html2pdf and jsPDF libraries, which run entirely in your browser. Nothing is transmitted. The only external resources loaded are the libraries themselves from a CDN.

JPG to PDF Questions

Is my data safe?

Yes. All conversion happens locally in your browser. Your JPG files are never uploaded to any server. You can disconnect from the internet after the page loads and the tool will continue to work.

Can I combine multiple JPGs into one PDF?

Not directly with this tool — each JPG becomes its own single-page PDF. To combine them into one multi-page PDF, convert each JPG here, then use the Merge PDF tool to combine the results in the order you want.

What page size should I choose?

A4 is standard in most of the world. Letter is standard in the United States, Canada, and a few other countries. Legal is used for US legal documents. Use Fit to Image when you want the PDF page to match the image's own dimensions exactly, with no surrounding margin.

Are the images stretched to fit the page?

No. The converter preserves the image's aspect ratio. If the image's aspect ratio does not match the page's aspect ratio, white space appears on two sides rather than the image being distorted.

Will I lose image quality?

Not significantly. The images are embedded as high-quality JPEGs at 0.92 compression, which is visually near-lossless for most photographs. Choose High quality for the sharpest results when printing or archiving.

What is the difference between Low, Medium, and High quality?

The quality setting controls how many pixels are rendered per inch of PDF page. Low uses 1× scale (fastest, smallest file), Medium uses 1.5× (default), and High uses 2.5× (sharpest, largest file). The compression level is the same across all three.

What does Grayscale do?

Grayscale converts the image to shades of grey before embedding it in the PDF. This reduces file size by 30–50% and is often preferred for text-heavy scans where colour adds no information. The original colour image on disk is not modified.

Can I download all PDFs as a ZIP?

Yes. Click "Download All (ZIP)" in the results section to receive every converted PDF inside a single ZIP archive. The ZIP is generated in your browser using JSZip. Nothing is uploaded.

Can I convert other image formats?

Yes. The tool accepts any image format the browser can display — JPG, JPEG, PNG, WEBP, GIF, BMP, and HEIC (on browsers that support it). The output is always a PDF.

What happens to image metadata like GPS location?

EXIF metadata — GPS coordinates, camera model, capture date, and other tags — is not carried into the PDF. The image is redrawn onto a canvas and re-encoded, which strips metadata. This is good for privacy but means the original metadata is lost.

Is there a limit on how many files I can convert?

The practical limit is your device's memory. Dozens of typical photos work fine. Hundreds of very large images may be slow. For best performance, process in batches of 20–50 files at a time.

What is the maximum file size per image?

About 50 MB per image. Beyond that, the browser may struggle to load the image into memory. For very large images, resize them first using an image editor, then convert.
