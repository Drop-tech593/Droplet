PDF/A Versions Explained

PDF/A-1b Most Compatible

Uses JPEG 2000 compression. Ensures documents look identical across all viewers. Ideal for long-term archiving.

PDF/A-1a Accessible

Same as 1b but includes accessibility features like logical structure and tagged content. Better for screen readers.

PDF/A-2b Advanced Features

Supports JPEG 2000, layers, and transparency. Better for documents with high-quality images.

PDF/A-3b Embedded Files

Supports embedding any file type (XML, CAD, spreadsheets) alongside the PDF content. Best for complex documents.

Frequently Asked Questions

Is my data safe?

Yes! All conversions happen locally in your browser. Your PDF is never uploaded to any server and is automatically deleted when you close the page.

What is PDF/A and why use it?

PDF/A is an ISO-standardized version of PDF designed for long-term archiving. It ensures documents will look the same and be readable decades from now, making it ideal for legal documents, academic papers, and historical records.

Which PDF/A version should I choose?

For most documents, PDF/A-1b is the most compatible choice. Use PDF/A-1a if you need accessibility features. For documents with high-quality images, choose PDF/A-2b. For documents with embedded files, choose PDF/A-3b.

Will my formatting be preserved?

Yes! PDF/A ensures all fonts, images, and formatting are embedded and preserved. Unlike regular PDFs, all resources are self-contained, ensuring the document looks the same everywhere.

Are there file size limits?

Since everything runs locally, limits depend on your device's memory. Most modern browsers handle PDFs up to 50MB without issues.
