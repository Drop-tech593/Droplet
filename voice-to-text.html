Voicepad guide

Speak and see words immediately

Choose your spoken language in Settings, then select Transcribe while speaking in Live Transcription. Allow the microphone when prompted. Early words appear under the button and each finished phrase moves into the editor. Press Stop listening when done.

Transcribe a recording

Drop an audio file into the upload box, or tap the folder to browse. To make a new recording, select Record Audio, speak, then press Stop Recording. Check the selected filename and press Transcribe Audio. Each file can be up to two hours 30 minutes long. Keep this tab open. Cancelling keeps completed text.

Choose a processing method

Browser speech service processes files at playback speed on supported browsers. Audio may be sent to the browser provider. On-device model downloads a speech model and processes the file locally. Start with Fast on a low-powered laptop. Larger models need more memory and time. These quality settings apply only to on-device files.

Edit, save and export

Starting a new live or file transcription clears the previous transcript. Download it first if you need a copy. Press Edit to type corrections, then Done to lock the text again. Automatic live reconnections continue the same transcript. The draft is saved in this browser. Choose DOCX for editable Word text, TXT for plain text, or PDF for fixed-layout pages. PDF pages are images. Download a copy before clearing browser data.

Conversation formatting and timestamps

Questions start separate blocks, followed by their answers. Brief exchanges stay separate; longer explanations form paragraphs, with a readability break after about 100 words or five sentences. Each block has its available timestamp above it. There is no fixed 30-second interval. These are punctuation-based formatting clues, not speaker identification or topic detection.

Live times approximate when results arrive. On-device files currently provide the start of each 25-second audio chunk, so several blocks within a chunk can share the same time. Exact question timings and reliable speaker changes are not available. Formatting cannot correct misheard words or recover missing audio.

Readable paragraphs

Select Format conversation to tidy an existing transcript without changing its words. Copy and downloads preserve the displayed blocks. Use Edit to adjust breaks or add speaker names. Older saved text retains only its saved timestamp positions.

Conversations and languages

Live dictation uses the single language selected in Settings. Automatic switching between languages, speaker labels and separation of overlapping voices are not available. For a video or meeting, uploading the original audio lets you retry processing without replaying it through a microphone. Speech during a live-service disconnection is not captured.

If something goes wrong

Microphone denied? Open Voicepad in its own browser tab, open the permissions beside the site address, allow Microphone and reload. Incorrect words? Check the spoken language and the microphone selected on your device. File processing stalls? Check the status under Transcribe Audio. Cancel and try a different method, or try Fast for on-device processing. Completed text stays after cancellation or an error. Starting a new transcription clears it.
