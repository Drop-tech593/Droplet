Supported Field Types

You can place six different kinds of fields on top of any page in your PDF:

  • Text input — a single-line box for names, addresses, account numbers, or any short answer. Default size is 200×32 pixels; you can resize it in the editor.
  • Checkbox — a small box that toggles between checked and unchecked. Useful for “I agree” statements and multi-select lists.
  • Radio button — a round selector for mutually exclusive choices. Each radio is independent in this tool, so place one per option and label them clearly.
  • Dropdown — a select-style field with a list of options that you define in the editor. Options are entered one per line.
  • Date field — a text field labelled for date entry. You type the date yourself; there is no calendar popup.
  • Signature placeholder — a wider box with a cursive font for typing a name as a signature. This is a visual placeholder, not a cryptographic signature.

Filling an Existing PDF Form vs. Creating New Fields

This tool does not read or write native PDF AcroForm fields. If your PDF was created with a real form (the kind you can tab through in Adobe Reader), those fields are not detected or editable here.

Instead, the tool works visually. You place new fields on top of the rendered page at the positions where you want them. This is the right approach for:

  • Flat PDFs (scans, exports, print-to-PDF) that have no interactive fields.
  • Forms that were never created as AcroForms in the first place.
  • Adding extra fields — like a signature line or a date stamp — to a form that already has some fields.
  • Building a fillable overlay on top of any PDF, regardless of how it was made.

Because the fields are visual overlays, they behave like annotations. They do not become part of the PDF's form structure, and they are not tab-navigable in a reader. They are, however, fully visible and printable in the exported PDF.

Placing and Moving Fields

Click any field type in the toolbar to add a field. It appears in the centre of the current page and opens an editor where you can set the label, value, width, height, and (for dropdowns) the option list.

Once placed, you can drag a field to reposition it anywhere on the page. Click a field again to reopen the editor and change its properties. The field list on the right shows every field in the document; clicking an entry selects it and jumps to its page.

Multi-Page Documents

Each field is assigned to the page where you created it. When you navigate between pages with the arrow buttons, only the fields for the current page are shown. Fields on other pages remain stored and are rendered in the export.

If you move a field and later change the page, the field stays with its original page. To move a field to a different page, delete it and recreate it on the target page.

Export — What the Output PDF Contains

When you click Export, the tool renders every page of the source PDF at high resolution and draws each field on top as a coloured rectangle with the label or value inside. The result is a new PDF where the fields are visible exactly where you placed them, styled consistently with the preview.

The exported PDF is flat. The fields are drawn as content, not as interactive widgets. Anyone opening the file will see the filled values, but they cannot click into the fields and change them. This is the right behaviour for a completed form that you want to send as a final copy.

If you need the recipient to be able to fill the form themselves, export without values, or use a dedicated AcroForm authoring tool instead.

Privacy — Everything Runs Locally

PDF rendering uses the open-source PDF.js library and PDF generation uses html2pdf, both of which run entirely in your browser. Your PDF is read into memory and never transmitted. The only external resources loaded are the libraries themselves from a CDN.

Practical Examples

Adding a signature line to a scanned contract: Load the scanned PDF, navigate to the signature page, add a Signature field near the bottom, type the signer's name, and export.

Creating a simple order form from a plain PDF: Add text fields for name, address, and quantity, a dropdown for product selection, and a checkbox for terms acceptance. Export when done.

Stamping a date on every page of a report: Add a Date field to page 1, navigate to the next page, add another Date field, and repeat. Each page gets its own date placeholder.

Adding radio-style choices to a questionnaire: Place one radio field per option in a row, label each one, and leave them unchecked for the recipient to complete on paper or in the exported PDF.

PDF Forms Questions

Does this tool read existing PDF form fields?

No. This tool does not detect or edit native AcroForm fields. It places new fields as visual overlays on top of the rendered page. If your PDF has interactive fields, they will appear in the background image but cannot be filled here.

Are the exported fields interactive?

No. The exported PDF is flat. Fields are drawn as visible content with their values, but they cannot be clicked or edited in a PDF reader. This is intentional — it makes the exported file a finished copy rather than an editable form.

What field types are supported?

Six types: text input, checkbox, radio button, dropdown, date field, and signature placeholder. Dropdown options are defined by you in the field editor. Signature is a visual placeholder, not a cryptographic signature.

Can I add fields to a scanned PDF?

Yes. Scanned PDFs work well because the tool operates on the rendered image. You place fields visually over the scan, fill them in, and export. The scan itself is unchanged.

Can I move a field to a different page?

Not directly. Fields are assigned to the page where they were created. To move a field to another page, delete it and recreate it on the target page.

Is there a limit to how many fields I can add?

There is no hard limit. Performance depends on the number of pages and the total number of fields. For most everyday documents, dozens of fields work smoothly. Very large documents with hundreds of fields may take longer to export.

Does the export preserve the original PDF quality?

The tool renders each page at 2× scale and embeds it as a high-quality JPEG. For text-heavy documents the result looks identical at normal reading sizes. For documents with very fine vector line work, there may be slight softening compared to the original.

Can I clear all fields and start over?

Yes. Click “Clear All Fields” in the field panel to remove every field at once. The source PDF stays loaded, so you can start placing new fields immediately.

Can I use this to sign a PDF?

You can add a signature placeholder and type a name into it. The signature appears in a cursive font in the exported PDF. This is a visual signature, not a digital signature. For legally binding digital signatures, use a dedicated e-signature service.

Is my PDF uploaded to a server?

No. All rendering, field placement, filling, and export happen locally in your browser. Your file never leaves your device. You can disconnect from the internet after the page loads and the tool will continue to work.

Why is the exported file a flat PDF instead of a fillable form?

Creating a real fillable form requires writing AcroForm structures into the PDF, which is a different operation from drawing visible content. This tool focuses on the visual overlay approach because it works with any PDF — including scans and flat exports that have no existing form structure.

Can I edit the exported PDF afterwards?

The exported PDF is a normal PDF file. You can open it in any reader or editor. However, the fields are drawn as content, so you cannot click into them and change the values. To change a value, go back to this tool, adjust the field, and export again.
