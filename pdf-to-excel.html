Frequently Asked Questions

Is my data safe?

Yes! All conversions happen locally in your browser. Your PDF is never uploaded to any server and is automatically deleted when you close the page.

How does the table detection work?

The tool analyzes the text layout in your PDF and identifies structured data patterns that resemble tables. It then extracts this data into rows and columns for your Excel spreadsheet.

Will it work with scanned PDFs?

This tool works best with text-based PDFs. Scanned/image-based PDFs require OCR (Optical Character Recognition) to extract text before tables can be detected.

What's the difference between "Detect Tables" and "Extract All Text"?

"Detect Tables" intelligently finds table structures in your PDF. "Extract All Text" puts all the text content into a single column, which is useful for unstructured data.

Are there file size limits?

Since everything runs locally, limits depend on your device's memory. Most modern browsers handle PDFs up to 50MB without issues.
