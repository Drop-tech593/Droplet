PDF to Excel Questions

How do I convert a tender BOQ document to Excel?

Upload your tender or BOQ PDF to Droplet's PDF to Excel converter. The document is analyzed for table data, which can then be exported as an editable XLSX spreadsheet.

How do I convert a BOQ PDF to Excel without breaking formatting?

BOQ documents may contain repeated headers, merged cells, multi-line descriptions and complex column layouts. Droplet analyzes the table structure when reconstructing the spreadsheet.

Can I extract a multi-page BOQ PDF to Excel?

Multi-page BOQ documents can contain tables that continue across several pages. Droplet processes the detected table data and exports the results to Excel.

How do I fix broken tables when converting BOQ PDF to Excel?

If a table appears broken, try switching the Document Type to a more specific mode (e.g. BOQ), or adjust the "Include headers & titles" setting. The converter relies on consistent column positions across pages.

Is my data safe?

Yes! All conversions happen locally in your browser. Your PDF is never uploaded to any server.

Which document type should I choose?

BOQ for construction Bills of Quantities. Invoice for supplier or service invoices. Bank Statement for account statements. Generic Table for any other tabular PDF.

What if the converter finds nothing?

The tool will tell you that no matching table was found. Try a different document type from the dropdown, or check that the PDF is text-based and not a scanned image.

Does it handle scanned PDFs?

No. Scanned PDFs are images and require OCR. This tool only works on PDFs that contain real text.

Are there file size limits?

Since everything runs locally, limits depend on your device. Most modern browsers handle PDFs up to 50MB.
