Frequently Asked Questions

Is my data safe?

Yes! All conversion happens locally in your browser. Your HTML files are never uploaded to any server.

What HTML features are supported?

Text, images, tables, lists, CSS styling, and most standard HTML elements. External stylesheets and scripts may have limitations.

Can I convert a website URL?

Yes, but external URLs may be blocked by CORS policies. For best results, save the HTML file first and upload it, or paste the HTML code directly.

Will external CSS and images work?

Inline styles and embedded images work best. External resources may not load due to security restrictions. Consider embedding styles and images directly in your HTML.

What about JavaScript?

JavaScript is not executed during conversion for security reasons. Only the static HTML and CSS are rendered.
