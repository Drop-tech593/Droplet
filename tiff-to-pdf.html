How TIFF to PDF Conversion Works

The converter reads your TIFF file in the browser using the open-source UTIF.js library. It decodes each frame (called an IFD — Image File Directory) inside the TIFF, converts the pixels to RGBA, draws them onto a canvas, and then renders each canvas as a page in the PDF. Everything happens locally on your device.

The final PDF is built using html2pdf, which rasterises each canvas and places it on a page at the size you choose.

Multi-Page TIFF — One Frame Becomes One PDF Page

A TIFF file can contain more than one image. Each of those images is called a frame or a page, and each one is stored in its own Image File Directory (IFD) inside the file. Multi-page TIFFs are common in faxes, medical imaging, scanned document archives, and photography.

This converter handles multi-page TIFFs natively. The mapping is simple and predictable:

  • Each frame in the TIFF becomes exactly one page in the PDF.
  • A single-frame TIFF produces a one-page PDF.
  • A five-frame TIFF produces a five-page PDF.
  • A fifty-frame TIFF produces a fifty-page PDF.

The page order matches the frame order in the TIFF. Frame 1 becomes page 1, frame 2 becomes page 2, and so on. No reordering happens during conversion.

When you convert a batch of TIFF files, each file produces one PDF. A two-file batch where the first file has three frames and the second file has one frame produces two PDFs — a three-page PDF and a one-page PDF.

Image Dimensions and Page Sizing

TIFF files store each frame's width and height in pixels. The converter reads those dimensions and renders each frame at its native pixel size onto the page.

Four page-size options are available:

Option Behaviour
A4 (210 × 297 mm) Frame is centred on an A4 page, scaled to fit within the printable area.
Letter (8.5 × 11 in) Same behaviour on a US Letter page.
Legal (8.5 × 14 in) Same behaviour on a US Legal page.
Fit to Image PDF page is exactly the size of the frame, with no surrounding paper.

Aspect ratio is always preserved. A landscape frame stays landscape, a portrait frame stays portrait. If the frame's aspect ratio does not match the page's aspect ratio, white space appears on two sides rather than the image being stretched or cropped.

For borderless results, choose Fit to Image. This is common when the TIFF already has its own border or when the PDF is intended for digital-only use.

Image Quality and Compression

TIFF is usually a lossless format, meaning the original pixel data is stored without any compression artefacts. The PDF format supports both lossless and lossy image data, so the converter must choose how to compress the frames when embedding them.

The Image Quality setting controls this:

Setting Rendering Scale Typical Use
Low (Faster) 1× Quick previews, small PDFs for email, thumbnails
Medium 1.5× General use, sharing, archiving — the default
High (Better Quality) 2.5× Printing, detailed scans, archival copies

Higher scales produce sharper images at the cost of larger files. JPEG compression is applied at 0.92 quality, which is visually near-lossless for photographs and scans. For text-heavy scanned documents, Medium quality is usually more than enough.

Note that the original TIFF's own compression scheme (LZW, ZIP, JPEG-in-TIFF) is discarded during decoding. The output PDF uses JPEG compression regardless of the input method.

Colour and Grayscale

Two colour modes are offered:

  • Colour — preserves the original RGB channels of each frame. Use this for photographs, colour scans, and any image where colour carries information.
  • Grayscale — converts each pixel to luminance using the standard formula (0.299 R + 0.587 G + 0.114 B). This reduces file size by roughly 30–50% and is often preferred for text documents, faxes, and line-art scans where colour adds nothing.

Grayscale is applied per pixel, so the output is a true greyscale image, not a colour image with desaturated pixels. This produces cleaner results and smaller files.

What Is Preserved and What Is Not

Preserved:

  • Frame count and order (one frame = one page).
  • Pixel dimensions and aspect ratio of each frame.
  • Full colour data (in colour mode).
  • Alpha channel handling — transparent areas are rendered against white.

Not preserved:

  • TIFF metadata — EXIF, GPS coordinates, camera model, and ICC colour profiles are stripped during decoding. The output PDF does not carry them.
  • TIFF-specific colour spaces — CMYK TIFFs are converted to RGB. Lab TIFFs are converted to RGB. The output is always sRGB-ish.
  • Layer information — if the TIFF contains layers (rare, but some formats support it), only the flattened composite is used.
  • Annotations or overlays — non-pixel data attached to the TIFF is not rendered.

Practical Examples

Converting a fax to PDF: A fax machine usually produces a single-page or multi-page TIFF at low resolution and monochrome. Upload the TIFF, choose A4, Medium quality, and Grayscale. The result is a small, clean PDF.

Archiving scanned photographs: A flatbed scanner may produce high- resolution TIFFs, one per photo. Upload them in a batch, choose Fit to Image, High quality, and Colour. Each photo becomes its own PDF at its native dimensions.

Digitising medical or legal records: Multi-page TIFFs are common in these fields. Upload the file, choose A4, High quality, and Grayscale (if the pages are monochrome text). The multi-page TIFF becomes a multi-page PDF with the same page order.

Preparing images for print: For print, use A4 or Letter, High quality, and Colour. The PDF preserves the detail at the resolution needed for output.

Reducing file size for email: Upload the TIFFs, choose A4, Low quality, and Grayscale. A 50 MB TIFF can produce a PDF under 1 MB, small enough to email.

Privacy — Client-Side Conversion

TIFF parsing uses the open-source UTIF.js library and PDF generation uses html2pdf. Both run entirely in your browser. Your TIFF files are read into memory and never transmitted. The only external resources loaded are the libraries themselves from a CDN. You can disconnect from the internet after the page loads and the tool will continue to work.

TIFF to PDF Questions

Is my data safe?

Yes. All conversion happens locally in your browser using UTIF.js. Your TIFF files are never uploaded to any server. You can disconnect from the internet after the page loads and the tool will continue to work.

How does this converter handle multi-page TIFF files?

Each frame (page) inside the TIFF becomes one PDF page. A five-frame TIFF produces a five-page PDF. A single-frame TIFF produces a one-page PDF. Page order matches frame order, and the page count of the output equals the frame count of the input.

Will I lose image quality?

The original TIFF is decoded and re-encoded as a JPEG inside the PDF. At High quality, the loss is visually imperceptible for most content. At Low quality, the file is smaller but small text and fine detail may soften. For archival, use High.

What page sizes are available?

A4, Letter, Legal, and Fit to Image. The first three place the frame on a standard page with a small margin. Fit to Image makes the PDF page exactly the size of the frame, with no surrounding paper.

Can I convert multiple TIFF files at once?

Yes. Drag and drop several TIFF files or select them all in the file picker. Each file produces its own PDF, and multi-page TIFFs produce multi-page PDFs. You can then download everything as a ZIP or individually.

Does it support CMYK or Lab TIFFs?

The converter reads RGB values from each frame. CMYK and Lab TIFFs are converted to RGB during decoding. The output PDF is always in RGB colour space. Colours may shift slightly if the original was in a wide-gamut space.

What does Grayscale do?

Grayscale converts each pixel to a single luminance value using the standard formula (0.299 R + 0.587 G + 0.114 B). This reduces file size by 30–50% and is often preferred for text-heavy scans and faxes where colour adds no information.

Will the PDF preserve the exact pixel dimensions?

Each frame is rendered at its native pixel dimensions multiplied by the quality scale. At Medium quality (1.5×), a 1000×1500 TIFF frame produces a PDF page containing a 1500×2250 pixel image. At High (2.5×), it produces 2500×3750 pixels. Choose Fit to Image to keep the PDF page at exactly the frame's natural size.

Is the TIFF metadata (GPS, camera model) preserved?

No. TIFF metadata is stripped during decoding. The output PDF does not carry EXIF, GPS coordinates, camera model, capture date, or ICC colour profiles. This is good for privacy but means the original metadata is lost.

Can I download all PDFs at once?

Yes. Click "Download All (ZIP)" in the results section. Every converted PDF is packaged into a single ZIP archive generated in your browser using JSZip. Nothing is uploaded.

What is the maximum file size?

About 100 MB per TIFF file. Very large multi-page TIFFs with hundreds of frames may be slow to process and use significant memory. For best performance, split very large files into smaller batches.

Can I convert other image formats?

The tool accepts any image format the browser can decode — JPG, PNG, WebP, GIF, BMP, and TIFF. The output is always a PDF. For the best multi-page experience, TIFF is the format that natively supports multiple frames in a single file.
