Frequently Asked Questions

Is my data safe?

Yes! All conversion happens locally in your browser. Your EPS files are never uploaded to any server.

What EPS features are supported?

Basic vector paths, shapes, lines, text, and colors are supported. Complex PostScript features (gradients, transparency, embedded fonts) may be simplified.

What about embedded images?

If your EPS contains embedded raster images, they are extracted and embedded as base64 PNG data in the SVG output. This may increase the SVG file size.

Can I convert multiple EPS files at once?

Yes! Drop or select multiple EPS files and all of them will be converted. You can download them all at once as a ZIP file.

Will my fonts be preserved?

Text elements are extracted and rendered using SVG text elements. If the original font isn't available in the SVG, it will fall back to a system font. For best results, convert text to paths in your EPS editor first.

What is the difference between EPS and SVG?

EPS is a PostScript-based format for print. SVG is an XML-based format for the web. SVG is easier to edit, smaller in size, and works natively in browsers.
