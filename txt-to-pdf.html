What the Converter Does

The tool reads your plain text file, parses its structure line by line, and renders it as a styled document that is then written out as a PDF. It detects headings, paragraphs, and simple lists, and applies consistent typography and spacing so the output looks like a professionally typeset document rather than a raw text dump.

Everything happens in your browser. Your text file is read into memory, formatted, rendered on a canvas, and written as a PDF. Nothing is uploaded.

Fonts

The PDF uses Georgia, a classic serif typeface designed for readability in long-form documents. Georgia is a web-safe font available on every platform, so the output renders consistently in Adobe Reader, Preview, Chrome, and every other PDF viewer.

Serif fonts are the traditional choice for body text in books, reports, and letters because the small strokes on each letter help the eye move smoothly along lines of text. If your source was a technical manual that used a monospace font, the PDF will render it in Georgia — the layout will be readable but the "typewriter" feel will be lost.

Font size is controlled by the "Font Size" option. Options are 10 pt, 11 pt, 12 pt, and 14 pt. The default is 11 pt, which matches the body text size used in most business documents and books.

Page Size

Three page sizes are offered, matching the standards used around the world:

Option Dimensions Region
A4 210 × 297 mm Most of the world (Europe, Asia, Africa, Oceania)
Letter 8.5 × 11 in United States, Canada, Mexico, Philippines
Legal 8.5 × 14 in US legal documents, contracts, court filings

The default is A4. If you are producing a document for a US audience or a legal filing, switch to Letter or Legal respectively. Page size affects pagination, so a long document will produce different page counts on different sizes.

Margins

Margins are set to 20 mm top and bottom, and 25 mm left and right. This is slightly wider than the defaults in most word processors, which gives the page a more open, readable feel. Text blocks are centred within the printable area.

Margins are fixed in this version. They match the proportions used by most academic and business documents. If you need tighter margins — for example to fit more text on a page — the PDF can be edited after download in a PDF editor.

Text Wrapping and Line Breaks

Plain text files use hard line breaks to separate lines. When the converter builds the PDF, it re-flows those lines into paragraphs. A new paragraph begins when a blank line appears in the source or when a line is detected as a heading or list item. Within a paragraph, text wraps naturally to fill the page width.

This means the output does not preserve the exact line breaks from the source file. If the original text had a hard break in the middle of a sentence — common in files exported from old systems — the converter joins it back into a single flowing sentence.

Text is justified, meaning both the left and right edges of each paragraph line up. This produces clean, uniform blocks of text. If you prefer ragged-right text, you would need to edit the PDF afterwards.

Pagination

Pages are generated automatically as the content grows. There is no manual page-break control in this version. The renderer breaks the document where it runs out of space, and continues on the next page.

Because the page-break positions depend on the font size, line spacing, and page size you choose, the same text file can produce different pagination with different settings. A 12 pt A4 document will have more pages than the same text at 10 pt A4. For predictable pagination, choose your settings before generating the PDF and keep them consistent.

The "avoid-all" page-break mode is used, which prevents the renderer from splitting a paragraph across two pages when possible. If a paragraph is longer than a full page, it will still break, but most normal paragraphs stay intact.

Line Spacing

Three line-spacing options are available: 1.5, 1.8, and 2.0. The default is 1.8, which is slightly airier than the 1.5 used by many word processors. Wider spacing makes long documents easier to read, especially on screen. Narrower spacing fits more text per page.

Line spacing is a multiplier on the font size. At 11 pt with 1.8 spacing, the distance between baselines is about 19.8 pt, which produces roughly 35 lines per A4 page with the default margins.

Unicode and Character Encoding

Text files can be saved in several encodings. The converter assumes UTF-8, which is the modern standard and covers virtually every character in every written language — Latin letters with accents, Greek, Cyrillic, Arabic, Hebrew, Chinese, Japanese, Korean, and the full range of emoji.

If your file is saved as UTF-8, non-English text and special characters will render correctly. If your file uses a legacy encoding like Windows-1252 or ISO-8859-1, characters outside the basic ASCII range may appear garbled. To fix this, open the file in a text editor, save it as UTF-8, and try again.

Two common encoding pitfalls to watch for:

  • Byte order mark (BOM) — a UTF-8 BOM at the start of the file appears as an invisible character. Some editors add it automatically. If your first line looks strange, remove the BOM.
  • Smart quotes and em-dashes — a UTF-8 file can contain curly quotes (" " ' ') and em-dashes (—), which render correctly. A non-UTF-8 file with these characters will show mojibake like â€™.

Heading Detection

The converter applies a few simple heuristics to detect headings:

  • Lines that are entirely uppercase and longer than three characters become headings.
  • Lines followed by a row of equals signs (====) or hyphens (----) become headings, and the underline row is removed.
  • Markdown-style headings (#, ##, ###) are recognised and converted to level 1, 2, and 3 headings.

Simple list items starting with -, *, or a number followed by a period are converted to bulleted or numbered lists.

There is no manual heading control. If a line is detected as a heading that you wanted as body text, or vice versa, you would need to edit the PDF afterwards.

Output Controls — What Each Setting Does

Four settings control the output:

Page size A4, Letter, Legal Changes page dimensions and pagination
Font size 10, 11, 12, 14 pt Changes body text size and page count
Line spacing 1.5, 1.8, 2.0 Changes vertical rhythm and page count

When the title page is enabled, the first page of the PDF is a cover showing the filename without its extension as the title, the full filename as a subtitle, and the conversion date. The body of the document starts on page 2. This is useful for reports and letters, but unnecessary for quick conversions.

What Is Not Preserved

  • Original line breaks — hard line breaks are joined into paragraphs.
  • Original fonts — everything is rendered in Georgia.
  • Tabs and column alignment — tabs become spaces, and columns do not align. If your file has tabular data, it will appear as a single stream of text.
  • Unicode emoji — some PDF viewers do not render emoji even if the PDF contains them. Simple emoji work; complex ones may appear as placeholder boxes.
  • Hyperlinks — URLs appear as plain text, not clickable links.

Privacy — Client-Side Conversion

Text reading uses the browser's built-in File.text() API, and PDF generation uses the open-source html2pdf library. Both run entirely in your browser. Your text is never transmitted. The only external resources loaded are the libraries themselves from a CDN.

TXT to PDF Questions

Is my data safe?

Yes. All conversion happens locally in your browser. Your text file is never uploaded to any server. You can disconnect from the internet after the page loads and the tool will continue to work.

Can I customize the PDF?

Yes. You can choose the page size (A4, Letter, Legal), font size (10–14 pt), line spacing (1.5, 1.8, 2.0), and whether to include a title page. The preview updates automatically as you change settings.

What font does the PDF use?

Georgia, a classic serif typeface available on every platform. Serif fonts are the traditional choice for body text in books and reports because they are easier to read in long passages. Font size is controlled by the Font Size option.

What page size should I choose?

A4 is standard in most of the world. Letter is standard in the United States, Canada, and a few other countries. Legal is used for US legal documents. If you are unsure, A4 is a safe default.

Will my line breaks be preserved?

No. The converter joins lines into flowing paragraphs and re-wraps the text to fill the page width. This produces a cleaner, more readable document. If you need the exact original line breaks, PDF is not the right format — use a plain text viewer instead.

How does pagination work?

Pages are generated automatically as the content grows. There is no manual page-break control. The renderer tries to avoid splitting a paragraph across two pages, but very long paragraphs will still break.

Does it support Unicode and non-English text?

Yes, as long as your file is saved as UTF-8. Non-English scripts, accents, and emoji will render correctly. If your file uses an older encoding like Windows-1252, save it as UTF-8 first.

Will headings and lists be detected?

Simple heuristics are applied. All-uppercase lines become headings. Lines underlined with equals signs or hyphens become headings. Markdown-style headings (#, ##, ###) are recognised. Lines starting with -, *, or a number followed by a period become list items.

What does the title page contain?

The title page shows the filename without its extension as the title, the full filename as a subtitle, the conversion date, and a small "Converted by Droplet" footer. The body of the document starts on page 2. Title page is optional.

Are tabs and column alignment preserved?

No. Tabs become spaces, and column alignment is not preserved. If your file contains tabular data, it will appear as a single stream of text. For tables, use a different converter that handles structured data, such as the CSV-to-PDF or DOCX-to-PDF tools.

Can I convert a password-protected file?

Plain text files cannot be password-protected in the way PDFs can. If your text is inside an encrypted archive (ZIP, RAR), extract it first, then upload the .txt file here.

What is the maximum file size?

About 10 MB. Beyond that, browser memory and rendering speed become limiting factors. A 10 MB text file contains roughly 10 million characters — around 1.5 million words — which is far more than a normal document.
