How Slides Become PDF Pages

The converter opens the PPTX file, reads each slide's XML, and extracts the text content — titles, bullet points, and body paragraphs. It then rebuilds that content as a styled HTML page and exports the whole set as a PDF, one slide per page.

The rebuilt page is not a pixel-perfect copy of the original slide. It has its own clean layout: a title at the top, a divider line, then the body text below. This is by design — it produces a readable, consistent PDF even when the original slide had overlapping text boxes, complex positioning, or themed backgrounds.

Page Dimensions and Orientation

Two page formats are available:

  • 16:9 widescreen — 297 mm × 167 mm. Matches modern projectors and screens, and is the default for most PowerPoint presentations created after 2013.
  • 4:3 standard — 254 mm × 190.5 mm. Matches older projectors and presentations created before the widescreen transition.

You can also choose Landscape or Portrait orientation. Landscape is the default and matches the shape of a presentation slide. Portrait rotates the page 90 degrees, which is useful for handouts that will be printed and bound on the short edge.

Fonts

The output PDF uses Arial (or Helvetica as a fallback), a standard sans-serif font that is available on every platform. The original slide's font family is not preserved. If the PPTX used Calibri, Roboto, Montserrat, or a custom corporate font, the PDF will render the text in Arial instead.

Font size is normalised: titles are set at 24 pt and body text at 14 pt, regardless of the original sizes. This keeps the output consistent across slides but means a slide that used very large or very small text will look different in the PDF.

Images

Images embedded in the slides are not extracted or placed in the PDF. The current version reads text only. If your presentation relies on charts, diagrams, logos, or photos, they will be missing from the output PDF. To include them, you would need to convert the presentation in a tool that renders each slide as an image, or add the visuals to the PDF manually afterwards.

Speaker Notes

Speaker notes are not included in the PDF. Notes live in a separate part of the PPTX (the notesSlide XML files) and the converter does not read them. If your notes are important for the audience, print them separately or copy them into a handout document.

Animations and Transitions — What Happens

This is the most important limitation to understand. PDF is a static, print-oriented format. It has no concept of timed reveals, motion, or slide-to-slide transitions. So:

  • Animations are dropped. If a bullet point was set to appear on click, it will simply appear on the PDF page as normal text. If a shape was set to fly in, it will just be part of the page (or missing, if it was an image).
  • Transitions are dropped. Any fade, push, wipe, or morph between slides is lost. Each slide is a standalone page in the PDF with no transition between pages.
  • Embedded video and audio are dropped. PDF supports embedded media in some readers, but this converter does not extract or re-embed it.
  • Hyperlinks are dropped. Clickable links inside the presentation are not preserved as clickable links in the PDF.

If you need the animations to be visible in the output, PDF is the wrong target format. Export to video (MP4) or keep the original PPTX. PDF is for sharing a static view of the content.

Legacy .PPT Files

Older PowerPoint files with the .ppt extension use a binary format that is very different from the modern .pptx ZIP-based format. This converter does not fully parse .ppt files. If you upload one, you will see a placeholder slide explaining that you need to re-save the file as .pptx in PowerPoint first. The conversion itself requires the modern format.

Practical Uses

Creating a text-only handout: Convert the presentation, print the PDF, and hand it out. The clean layout is easier to read than a slide screenshot.

Archiving the text of a deck: If you need to preserve the wording but not the visuals, this produces a searchable, copyable PDF.

Extracting content for documentation: Convert to PDF, then copy the text into a manual, wiki, or spec document. The layout is already clean.

Privacy — Client-Side Conversion

PPTX parsing uses the open-source JSZip library and PDF generation uses html2pdf. Both run entirely in your browser. Your presentation is read into memory and never transmitted. The only external resources loaded are the libraries themselves from a CDN.

PowerPoint to PDF Questions

Will my slides look exactly like the original?

No. The converter extracts the text content and rebuilds it in a clean, consistent layout. Titles, bullet points, and body text are preserved, but the original fonts, colours, backgrounds, images, and exact positioning are not. The output is a readable text-oriented PDF, not a pixel-perfect copy.

Are animations and transitions preserved?

No. PDF is a static format with no concept of animation or transition. All motion is dropped. If a bullet point was set to appear on click, it appears normally on the PDF page. If a slide had a fade-in transition, the PDF page simply follows the previous one.

Are images and charts included in the PDF?

No. The current version reads text only. Images, charts, diagrams, and logos embedded in the slides are not extracted or placed in the output PDF. This is a text-extraction converter, not a slide renderer.

Are speaker notes included?

No. Speaker notes are stored separately in the PPTX file and are not read by this converter. If your notes matter for the audience, print them separately or copy them into a handout document.

What page size does the PDF use?

16:9 widescreen (297 mm × 167 mm) or 4:3 standard (254 mm × 190.5 mm). You can also choose landscape or portrait orientation. Landscape is the default and matches the shape of a presentation slide.

Are the original fonts preserved?

No. The output uses Arial (or Helvetica as a fallback) for all text. This is a standard font available on every platform. If your presentation used a custom corporate font, it will be substituted.

Can I edit the PDF after conversion?

The PDF contains real text, so you can select and copy it. To edit the content, use a PDF editor. To change the layout, fonts, or add images back in, edit the original PPTX and convert again.

Does the tool support legacy .PPT files?

Only partially. Legacy .ppt files use a binary format that is not fully parsed. You will see a placeholder slide asking you to re-save the file as .pptx in PowerPoint first.

Is my PowerPoint uploaded to a server?

No. All parsing and PDF generation happen locally in your browser using JSZip and html2pdf. Your file never leaves your device. You can disconnect from the internet after the page loads and the tool will continue to work.

Can I convert a password-protected PPTX?

No. The converter can only read PPTX files that open without a password. If your presentation requires a password, remove the protection first using PowerPoint, then convert it here.

What is the maximum file size?

About 100 MB. The practical limit depends on your device's memory, since everything runs in the browser. Very large presentations with hundreds of slides may take longer to process.

Why is the output so different from my slides?

Because this is a text-extraction converter, not a slide renderer. It reads the words on each slide and rebuilds them in a clean layout. If you need a visual copy of the slides, use PowerPoint's own "Save as PDF" feature or a slide-rendering tool instead.
