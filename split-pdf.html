Split a PDF into Multiple Files Without Uploading

This tool splits a PDF entirely in your browser. You choose how to divide the document — by a fixed number of pages, by custom ranges, or by picking individual pages — and the tool produces a set of new PDF files. Nothing is sent to a server, so contracts, reports, and personal documents stay on your device.

Splitting vs. Extracting — What's the Difference?

These two operations sound similar but produce different results. Understanding the difference helps you pick the right mode:

Operation What it does Example input Output
Split Divides the document into contiguous chunks. Every page appears in exactly one output. Every 3 pages, 10-page PDF 4 files: pages 1–3, 4–6, 7–9, 10
Split by range Divides the document into the exact ranges you specify. Pages outside the ranges are dropped. Ranges: 1-3, 7-9 2 files: pages 1–3 and 7–9. Pages 4–6 and 10 are excluded.
Extract Pulls out only the pages you select. Consecutive selections become one file; non-consecutive selections become separate files. Selected: 1, 2, 3, 7, 8 2 files: pages 1–3 and pages 7–8

In short: split partitions the whole document, while extract picks out specific pages and discards the rest. Use split when you want every page preserved; use extract when you only want some pages.

Split by Every N Pages

The simplest mode. Enter a number — for example, 1 to split every page into its own file, or 10 to produce a new PDF every ten pages. A 25-page document split with N=10 becomes three files: pages 1–10, pages 11–20, and pages 21–25.

Use this when you want evenly sized chunks, such as splitting a scanned book into chapters of equal length or breaking a long report into sections for emailing.

Split by Custom Ranges — Validation Rules

Custom ranges give you precise control. Type one or more ranges separated by commas, using a hyphen for a span and a single number for an individual page. Some examples:

  • 1-3 — one file containing pages 1, 2, and 3.
  • 1-3, 5, 8-10 — three files: pages 1–3, page 5, and pages 8–10.
  • 1, 4, 7, 10 — four single-page files.
  • 2-5, 12-15, 20-22 — three files, each covering a different section.

The tool validates every range before splitting. If any of the following problems are detected, you'll see an error message and the split will not start:

  • Out-of-range pages. A page number greater than the total page count, or a start page of 0 or less.
  • Reversed ranges. A range like 5-2 where the start is after the end.
  • Malformed input. Non-numeric characters, empty ranges, or missing numbers around a hyphen (e.g. 1- or -3).
  • Overlapping ranges. Two ranges that share pages, such as 1-5, 3-7. Overlapping ranges would produce duplicate pages in different output files, so they are rejected.

A live preview shows the valid ranges as chips and the total page count they cover, so you can confirm the split before clicking the button.

Extract Individual Pages

Extract mode shows a thumbnail grid of every page. Click a page to toggle it on or off, and the tool builds one or more PDFs from the selected pages. Consecutive selected pages are grouped into a single file; non-consecutive selections become separate files.

For example, if you select pages 1, 2, 3, 7, and 8, you get two output files: one containing pages 1–3 and another containing pages 7–8. If you want each selected page as its own file, use Custom Ranges with single page numbers, like 1, 5, 9.

Page Preview and Selection

When you load a PDF, the tool renders a small preview of every page. In Extract mode these previews are clickable — a blue border marks each selected page, and a counter shows how many pages you have chosen. This visual approach makes it easy to pick the right pages without having to remember page numbers.

Multiple Outputs and Batch Download

A single split operation can produce many files. After splitting, each output is listed with its filename, page count, and the range of pages it contains. You can download files individually, or click Download All (ZIP) to receive every result in a single ZIP archive. The ZIP is generated in your browser using JSZip — again, nothing is uploaded.

When there is only one output file, the “Download All” button downloads that single PDF directly instead of wrapping it in a ZIP, which is more convenient for the common case.

Privacy — Client-Side Splitting

PDF parsing uses the open-source PDF.js library, and PDF generation uses html2pdf, both of which run entirely in your browser. Your PDF is read into memory and never transmitted. The only external resources loaded are the libraries themselves from a CDN.

Practical Examples

Splitting a scanned book into chapters: Use Custom Ranges and enter the page ranges for each chapter, such as 1-24, 25-48, 49-72.

Extracting a single signed page from a contract: Use Extract mode and click only the signature page. The result is a one-page PDF.

Breaking a 100-page report into 10-page sections: Use Every N Pages with N=10. You get ten 10-page PDFs.

Separating invoices from a combined statement: Use Custom Ranges and enter the page span for each invoice, e.g. 1-2, 3-4, 5-6.

Split PDF Questions

How do I split a PDF into separate files?

Drop your PDF onto the upload area, choose a split mode (Every N Pages, Custom Ranges, or Extract Selected Pages), configure the options, and click Split PDF. The tool creates the new files in your browser and lists them for download.

What's the difference between splitting and extracting pages?

Splitting divides the whole document into contiguous chunks — every page ends up in exactly one output file. Extracting pulls out only the pages you select and discards the rest. If you want all pages preserved, use split; if you only want some pages, use extract.

Can I split a PDF by specific page ranges?

Yes. Choose Custom Ranges and enter the ranges using commas and hyphens. For example, 1-3, 5, 8-10 produces three files: pages 1–3, page 5, and pages 8–10. Each range becomes its own PDF. The tool validates your input and rejects out-of-range, reversed, or overlapping ranges before splitting.

What happens if my range is invalid?

The tool checks every range before splitting. If a page number is beyond the document's page count, a range is reversed (like 5-2), a range overlaps another range, or the input is malformed, you'll see a clear error message and the split will not start. Fix the range and try again.

Can I use overlapping ranges?

No. Overlapping ranges would produce duplicate pages in different output files, which is almost never what you want. The tool rejects overlapping ranges and shows an error so you can adjust them. If you genuinely need a page in two files, split once and repeat the operation on the relevant output.

How do I extract just one page from a PDF?

Use Extract Selected Pages mode and click the page you want in the thumbnail grid. Or use Custom Ranges and enter that single page number (for example, 7). Either way, the output is a one-page PDF.

Can I select non-consecutive pages to split?

Yes. In Extract mode, click any combination of pages. Consecutive selected pages are grouped into a single output file; non-consecutive pages become separate files. If you want each selected page as its own file, use Custom Ranges with single page numbers separated by commas, like 1, 5, 9.

Is there a limit to how many files I can create?

The practical limit is your device's memory and the number of pages in the source PDF. Splitting a 500-page PDF into 500 single-page files works, but it produces 500 output files and can take a moment. Most everyday documents split instantly.

Can I download all split files at once?

Yes. After splitting, click Download All (ZIP) to receive every output PDF inside a single ZIP archive. The ZIP is generated in your browser — nothing is uploaded. If there's only one output file, the button downloads that PDF directly.

Does splitting a PDF reduce its quality?

Each output page is rendered to a high-resolution image (2× scale) and re-embedded into a new PDF. For text documents the result is visually identical at normal reading sizes. For PDFs that contain vector graphics or selectable text, the output becomes image-based — the text is no longer selectable. If you need to preserve vector content, use a PDF library that operates on the original page objects rather than rendering to images.

Can I split a password-protected PDF?

No. The tool can only process PDFs that open without a password. If your PDF requires a password, remove the protection first using a dedicated PDF tool, then split it here.

Is my PDF uploaded to a server?

No. All parsing, splitting, and PDF generation happen locally in your browser using JavaScript. Your file never leaves your device. You can even disconnect from the internet after the page loads and the tool will continue to work.

What happens to the original PDF after splitting?

Nothing. The original file on your device is untouched. The split operation produces new PDF files (or a ZIP of them) for download. Your original PDF remains exactly as it was.

Can I reorder pages while splitting?

This tool does not reorder pages — it only divides the document. To reorder pages, use a dedicated PDF page-organizer tool first, then split the reordered file here. The Split PDF tool preserves the original page order within each output range.

Why are my output files named with “_part_1”, “_part_2”, etc.?

The tool uses the original filename as a base and appends _part_N so the outputs sort correctly and you can tell which piece is which. Each file also shows its page range in the results list so you can confirm the split before downloading.
